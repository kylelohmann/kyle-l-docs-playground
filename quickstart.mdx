In this guide, you start the demo API, make an authenticated request, and compare a player with the **Tour elite** cohort.

## Prerequisites

- Node.js 20 or later
- A clone of this repository

The demo app has no dependencies, so you don't need to run `npm install`.

## Make your first comparison

<Steps>
  <Step title="Start the API">
    From the repository root, run:

    ```bash
    cd app
    npm start
    ```

    The server listens on `http://localhost:4000`. To use another port, set `PORT`, for example `PORT=5000 npm start`.
  </Step>
  <Step title="List your players">
    Every request needs an API key in the `Authorization` header. The demo server accepts `sk_test_demo_123`.

    ```bash
    curl http://localhost:4000/v1/players \
      -H "Authorization: Bearer sk_test_demo_123"
    ```

    The response lists three sample players:

    | ID | Handicap index |
    | --- | --- |
    | `plr_sam_okafor` | 3.6 |
    | `plr_alex_rivera` | 11.8 |
    | `plr_jordan_lee` | 19.4 |
  </Step>
  <Step title="Compare a player with tour-level golfers">
    ```bash
    curl "http://localhost:4000/v1/players/plr_alex_rivera/compare?cohort=tour_elite" \
      -H "Authorization: Bearer sk_test_demo_123"
    ```

    The response shows where Alex loses strokes, along with insights you can show to the player:

    ```json
    {
      "cohort": { "id": "tour_elite", "name": "Tour elite" },
      "rounds_included": 20,
      "strokes_gained": {
        "total": -12.35,
        "by_category": [
          { "category": "approach", "label": "Approach", "strokes_per_round": -5.56 },
          { "category": "off_the_tee", "label": "Off the tee", "strokes_per_round": -3.02 },
          { "category": "around_the_green", "label": "Around the green", "strokes_per_round": -2.06 },
          { "category": "putting", "label": "Putting", "strokes_per_round": -1.71 }
        ]
      },
      "biggest_opportunity": "approach",
      "insights": [
        "You're 12.3 strokes per round behind the Tour elite cohort.",
        "Approach is your biggest gap at 5.6 strokes per round (45% of the total)."
      ]
    }
    ```

    The full response also includes a `metrics` array with each stat, the gap, and a cohort percentile.
  </Step>
  <Step title="Run the example script">
    The repository includes a script that prints the comparison as a table:

    ```bash
    node examples/compare.js plr_alex_rivera tour_elite
    ```

    Try `hcp_10` instead of `tour_elite` to see how Alex compares with golfers at a similar level.
  </Step>
</Steps>

<Tip>
  With the server running, you can also send requests from any endpoint page in the [API reference](/api-reference/introduction). Enter `sk_test_demo_123` as the bearer token.
</Tip>
