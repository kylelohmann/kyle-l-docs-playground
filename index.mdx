---

The Benchmarks API gives your app a golfer's Arccos rounds, stats, and strokes gained. It also compares them with benchmark cohorts, from tour-level players down to 20 handicaps.

Use it to build features like:

- A "How do you stack up against the pros?" screen that shows where a player loses strokes.
- A coaching dashboard that tracks a student's strokes gained over a season.
- Club fitting tools that compare a golfer's carry distances with better players.
- Notifications that fire the moment a round syncs.

<Warning>
  This is a demo. The API runs on your machine from the `app` folder and serves generated sample data for three fictional players. It is not an official Arccos API. Read [Production checklist](/build/production) before you build on real data.
</Warning>

## How it works

<Steps>
  <Step title="A player connects their Arccos account">
    The player appears in [`GET /v1/players`](/api-reference/players/list-players) for your API key.
  </Step>
  <Step title="Rounds sync">
    Arccos sensors record every shot. When a round finishes syncing, you receive a [`round.completed`](/guides/webhooks) webhook.
  </Step>
  <Step title="You read stats and compare">
    Call [`GET /v1/players/{playerId}/compare`](/api-reference/performance/compare-a-player-with-a-cohort) to see how the player measures up against any cohort.
  </Step>
</Steps>
